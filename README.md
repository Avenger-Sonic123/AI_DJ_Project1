# AI DJ — Interface

An initial interface for a planned wrist-controlled music player.

**Repository created:** 2022-10-26  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2022-10-26

## Features and implementation

- Song-name display.
- Wrist gesture instructions.
- Styled page with musical background.

## Technologies

HTML, CSS, JavaScript, Bootstrap, jQuery, p5.js, p5.sound, ml5.js.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |
| [`main.js`](main.js) | Project-specific JavaScript |
| [`style.css`](style.css) | Page styling |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/AI_DJ_Project1.git
cd AI_DJ_Project1
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Open the static DJ interface.

## Current status and limitations

The JavaScript file is empty; no audio tracks or pose-control implementation are present.
